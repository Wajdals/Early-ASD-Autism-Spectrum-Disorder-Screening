# Early-ASD-Autism-Spectrum-Disorder-Screening

Analyzes a public toddler ASD screening dataset from Saudi Arabia (Q-CHAT-10 based) to support early autism detection, grounded in research linking ASD comorbidities to higher healthcare utilization.

Pipeline: Data validation & cleaning (SQL) → correlation analysis → KPI dashboard.

KPIs: Screening volume, positive/negative rates, avg. age at positive screening, age/score patterns.

Key findings:
- 67% positive screening rate (341/506); well above general population base rates
- Avg. age at positive screening: ~25 months (out of a 12–36 month window)
- Highest-trait scores concentrated in the 30–36 month age band

Impact: Supports earlier ASD screening and faster referral-to-assessment pathways to improve care access before needs escalate.
